# StudyHub

Your student-support partner for academic assistance and creative digital services.

## Features
- Notes and revision material support
- PowerPoint presentation design
- Word and document formatting
- Excel and charts support
- Resume and portfolio support
- Project and interview preparation
- WhatsApp order enquiry form

## Deployment
This is a static website. The main entry point is `index.html`.

To deploy with Cloudflare Pages, connect this GitHub repository and use the repository root as the build output directory. No build command is required.
